# 좋아하면 울리는 💕

인스타그램 아이디를 기반으로 서로의 마음을 확인할 수 있는 익명 매칭 서비스입니다.

## 📱 서비스 소개

'좋아하면 울리는'은 누군가에게 마음이 있지만 먼저 고백하기 어려운 분들을 위해 만들어졌습니다. 상대방의 인스타그램 아이디만 알고 있다면, 내 아이디와 함께 등록하여 '알람'을 울릴 수 있습니다. 만약 상대방도 나에게 알람을 울렸다면, 양쪽 모두에게 매칭 성공 알림이 전달되어 서로의 마음을 확인할 수 있게 됩니다.

### 작동 원리

1. **알람 등록**: 내 인스타그램 아이디와 마음이 있는 상대방의 인스타그램 아이디를 입력하여 알람을 생성합니다.
2. **자동 매칭 확인**: 시스템이 자동으로 양방향 알람을 확인합니다. 즉, 내가 상대방에게 알람을 울렸고, 동시에 상대방도 나에게 알람을 울렸는지 실시간으로 검사합니다.
3. **매칭 성공 알림**: 양쪽 모두 서로에게 알람을 울린 경우, 화려한 축하 애니메이션과 함께 매칭 성공 모달이 표시됩니다.
4. **프라이버시 보호**: 일방적인 알람은 상대방에게 노출되지 않습니다. 오직 양쪽이 모두 알람을 울렸을 때만 매칭이 성립되므로, 거절당하는 부담 없이 안전하게 마음을 표현할 수 있습니다.

## ✨ 주요 기능

- ✅ **무료 첫 알람**: 모든 사용자는 첫 번째 알람을 무료로 생성할 수 있습니다.
- 💳 **알람 추가 결제**: 두 번째 알람부터는 결제로 슬롯 해제가 필요합니다 (개당 1,000원)
- 📋 **실시간 알람 관리**: 내가 생성한 모든 알람을 한눈에 확인할 수 있으며, 언제든지 삭제할 수 있습니다.
- 🎨 **직관적인 UI**: 토스에서 제공하는 TDS 시스템 바탕으로 깔끔하게 정리된 인터페이스
- 🎉 **매칭 축하 효과**: 매칭이 성공하면 컨페티 애니메이션과 함께 성공 화면이 표시됩니다.

## 🛠 기술 스택

- **Framework**: React 18.3.1
- **Build Tool**: Vite 7.2.4
- **UI Library**: TDS Mobile (@toss/tds-mobile)
- **Routing**: React Router DOM
- **Platform**: 토스 앱인토스 (Apps in Toss)
- **Storage**: LocalStorage

## 🚀 시작하기

### 사전 요구사항

- Node.js 18 이상
- npm 또는 yarn

### 설치

```bash
# 의존성 설치
npm install
```

### 개발 서버 실행

```bash
# 개발 모드로 실행
npm run dev
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다.

### 빌드

```bash
# 프로덕션 빌드
npm run build
```

### 배포

```bash
# 토스 앱인토스에 배포
npm run deploy
```

## ⚙️ 설정

### 아이콘 이미지 설정

SDK 3.x에서는 앱인토스 콘솔에서 앱 이름과 아이콘을 관리합니다. 빌드 설정은 `apps-in-toss.config.ts`를 사용합니다.

세션 인증 빌드의 검토·출시와 이전 API 종료 순서는 [세션 인증 전환](docs/SESSION_CUTOVER.md)을 참고하세요.

### 결제 상품 ID 설정

`src/components/PaymentModal.jsx` 파일에서 결제 상품 ID를 설정해야 합니다:

```javascript
await window.appsInToss.IAP.createOneTimePurchaseOrder({
  productId: 'alarm_slot_1000', // 앱인토스 콘솔에 등록한 실제 상품 ID로 변경
});
```

토스 앱인토스 콘솔에서 인앱 결제 상품을 등록한 후, 해당 상품 ID로 변경하세요.

## 🧪 테스트 방법

### 1. 기본 기능 테스트

#### 인트로 페이지 테스트
1. 앱을 처음 실행하면 인트로 페이지가 표시됩니다.
2. "확인했어요" 버튼을 클릭하면 알람 목록 페이지로 이동합니다.
3. 이후 앱 실행 시에는 자동으로 알람 목록 페이지로 이동합니다.

#### 알람 추가 테스트
1. 알람 목록 페이지에서 "+ 추가하기" 버튼을 클릭합니다.
2. 본인 인스타그램 ID와 상대 인스타그램 ID를 입력합니다.
3. 첫 알람은 무료로 추가됩니다.
4. 두 번째 알람부터는 결제 팝업이 표시됩니다 (개발 환경에서는 시뮬레이션).

#### 매칭 테스트
1. 같은 기기에서 두 개의 알람을 추가합니다:
   - 알람 1: 본인 ID: `user1`, 상대 ID: `user2`
   - 알람 2: 본인 ID: `user2`, 상대 ID: `user1`
2. 두 번째 알람을 추가하면 즉시 매칭 성공 화면이 표시됩니다.
3. 알람 목록에서 매칭된 알람은 ❤️ 아이콘으로 표시됩니다.

#### 알람 삭제 테스트
1. 알람 목록에서 "제거" 버튼을 클릭합니다.
2. 알람이 목록에서 제거되는지 확인합니다.

### 2. 결제 기능 테스트

#### 개발 환경
- 개발 환경에서는 결제가 시뮬레이션됩니다.
- 결제 팝업에서 "알람 슬롯 추가하기" 버튼을 클릭하면 0.5초 후 성공 처리됩니다.

#### 프로덕션 환경
- 토스 앱에서 실제 결제가 진행됩니다.
- 앱인토스 콘솔에서 인앱 결제 상품을 먼저 등록해야 합니다.

### 3. 로컬 스토리지 테스트

브라우저 개발자 도구의 Application > Local Storage에서 다음 키들을 확인할 수 있습니다:
- `love_alarm_alarms`: 알람 목록 데이터
- `love_alarm_first_used`: 첫 알람 사용 여부
- `love_alarm_count`: 알람 개수
- `has_visited_intro`: 인트로 페이지 방문 여부

### 4. 반응형 테스트

다양한 화면 크기에서 테스트:
- 모바일 (375px, 414px)
- 태블릿 (768px, 1024px)

### 5. 브라우저 호환성 테스트

- Chrome (최신 버전)
- Safari (최신 버전)
- 토스 앱 내 WebView
